# Architecture

High-level shape of the harness: an agent's tool calls pass through
permission -> execution -> workspace snapshotting -> verification ->
reconciliation -> gate decision -> evidence/receipt, with an append-only
hash-chained trace alongside every step.

This is a short index only. The full architecture writeup, including
diagrams, lives in `verified_execution_harness.pdf` (generated by
`../scripts/diagrams.py` + `../scripts/build_pdf.py`); this file exists so
the topic has a place in version-controlled Markdown as that PDF evolves.
See also: `harness.md`, `execution.md`, `verification.md`.
